# Getting Started

CodeShuttle sends your code to an AI chat and brings the answers back.

The round trip is the whole product:

1. **Pack** — choose a folder and the file types you care about, then press GENERATE.
2. **Send** — copy the pack, as plain text or wrapped in a prompt, and paste it into any AI chat.
3. **Bring it back** — paste the AI's reply into *Apply AI Changes*.
4. **Review** — every file is diffed against what is on disk. Tick the ones you want.
5. **Apply** — the accepted files are written, with a backup of the previous contents taken first.

Nothing is uploaded by CodeShuttle itself. It builds text and reads text; you decide what goes
where, using whichever AI you already pay for.

## Your first pack

- Type or browse to a folder in the box at the top left.
- Add at least one extension — `.cs`, `.py`, `.ts` — or pick a language bundle from **Add** > **Language presets**.
- Press **GENERATE**.

If nothing appears, the status bar will say how many files were skipped and why. Click it.
